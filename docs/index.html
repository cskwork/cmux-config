cmux-config View on GitHub

personal cmux config snapshot

A portable cmux.json you can drop into ~/.config/cmux/.

cmux stores most preferences in an opaque macOS plist. This repo file-manages only the overrides that matter, so a fresh machine can pick them up with one curl.

Install View on GitHub

// install

One curl.

# Drop the file-managed cmux config into place
mkdir -p ~/.config/cmux
curl -fsSL https://raw.githubusercontent.com/cskwork/cmux-config/main/cmux.json \
  -o ~/.config/cmux/cmux.json

Then press cmd + shift + , inside cmux to reload, or restart the app.

// active overrides

Just one knob, today.

Everything else falls back to the value saved in the in-app Settings panel or the cmux schema default. The full template is preserved as commented blocks so you can extend it later.
